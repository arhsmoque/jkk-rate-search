# jkk-rate-search frontend profile

- **Audience/job:** Estimators, engineers, QS staff, and contractors finding authoritative JKK rates and source evidence.
- **Dominant archetype:** Authoritative rate search and citation tool.
- **Signature behavior:** Rate evidence card pairing description, unit, rate, source document/page, and copy/download actions.
- **Priorities:** Fast keyboard search; safe highlighting; numeric alignment; filter persistence; no-result suggestions; offline resilience; printable evidence.
- **Verification:** Run repository validator; test shortcut, rapid typing, PDF/source links, mobile lookup, offline/error states, and exact rate formatting.

This profile is context, not a theme preset. Live repository instructions and product evidence override stale assumptions.
